## 📚 Informações gerais

Repositório contendo soluções de uma gama de exercícios, incluíndo os propostos nos treinamentos do projeto, de diversas plataformas: Codeforces, Beecrowd e Leetcode. Mantido pelo grupo [FACOMpetindo](https://linktr.ee/facompetindo) da FACOM/UFMS.

O repositório é dedicado a linguagem C++.

Esperamos que esse repositório seja muito útil para aqueles iniciando e/ou desejando se aprofundar na programação competitiva! No futuro planejamos adicionar explicações mais detalhadas para cada solução.

## 🫂 Contribuições

Contribuições são mais que bem-vindas, de qualquer exercício (mesmo os que já estejam nesse repositório), desde que o veredito na plataforma seja AC.

Para adicionar uma solução, simplesmente crie uma PR com uma ou mais soluções em suas pastas apropriadas (se é um contest oficial, gym, número do round etc).
